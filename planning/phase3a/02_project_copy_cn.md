## 1. The Making of Pets｜制作宠物
**类型：** 3D Animation / Speculative Design
**卡片一句话：** 一座被精心制造的动物乐园：当美丽成为规训的一部分。

**项目正文：** 以生态女性主义为研究线索，我通过一座虚构的动物乐园，讨论女性与自然如何在消费文化和权力结构中被塑造成可观看、可装饰的对象。作品将动物、植物、水、蕾丝与珍珠组合成梦幻的 3D 场景，让看似自由的“天堂”同时呈现人工控制与美化的矛盾。项目从角色与场景设计出发，完成建模、材质、灯光、关键帧动画、镜头与渲染，并通过影像组织完整的视觉叙事。

**技术与能力标签：** Cinema 4D · 3D Modeling · Keyframe Animation · Lighting & Rendering · Visual Storytelling

**创作职责：** 概念研究、角色与场景视觉设计、3D 建模、动画、灯光材质及渲染。

**完整动画：** https://www.youtube.com/watch?v=6AQrL53uet8

## 2. Anger Market｜愤怒市场
**类型：** Visual Identity / Speculative Design
**卡片一句话：** 把愤怒变成商品：一个关于平台算法与情绪消费的虚构品牌。

**项目正文：** Anger Market 以一家虚构的情绪数据公司为设定，将社交平台上的愤怒视为可以采集、分类、计量和交易的资源。我围绕“Anger Converter”构建品牌概念、图形语言与数据叙事，模拟情绪如何被转化为广告投放、舆论操作和平台留存的工具。项目通过具有讽刺意味的视觉系统，讨论个体表达、算法传播与商业利益之间的关系。

**技术与能力标签：** Brand Identity · Graphic Design · Data Storytelling · Speculative Design

**创作职责：** 概念研究、品牌设定、视觉识别、图形系统与数据叙事设计。

## 3. Chroma Residences: Living in Color｜色度住宅
**类型：** Spatial / Installation Design
**卡片一句话：** 从建筑空间比例出发，重新看待城市租住生活的“理想包装”。

**项目正文：** 项目以北京城市租住经验为切入点，观察共享空间被大量宣传、私人生活面积却不断压缩的现象。我设计了一组以不同阶层为隐喻的模块化住宅结构，利用空间比例、分层与材料表达居住体验的差异，并以装置呈现租赁市场中的公共与私人空间关系。作品将社会议题研究转译为可观察、可讨论的空间视觉系统。

**技术与能力标签：** Spatial Design · Cinema 4D · Arduino · Physical Model · Installation

**创作职责：** 城市议题研究、空间叙事、模块设计、3D 辅助建模与装置呈现。

## 4. Stubborn Horse｜固执的马
**类型：** Creative Coding / Interactive Web
**卡片一句话：** 一场无法通过“强行控制”获胜的互动喂食实验。

**项目正文：** Stubborn Horse 是一个基于 p5.js 的浏览器互动体验。玩家通过移动鼠标和投放草料引导马接近目标区域，但角色并不会机械地服从指令：过度催促反而会影响它的情绪。项目围绕状态反馈、平滑移动和简单规则建立可理解的互动循环，让玩家在等待、观察与尝试中学习“引导而非控制”。

**技术与能力标签：** p5.js · JavaScript · State-based Interaction · Creative Coding

**创作职责：** 角色与交互机制设计、p5.js 开发、状态与反馈逻辑、声音和视觉反馈。

**玩法演示：** https://www.youtube.com/watch?v=itmUY-1dSg8
**在线体验：** https://stubborn-horse.onrender.com

## 4.5. From Static Image to Motion: Algorithmic Reinterpretations of a Horse｜马的算法运动研究
**类型：** Generative Art / Motion Study
**卡片一句话：** 让手绘轮廓通过计算机视觉与算法重新获得运动。

**项目正文：** 这是与 Stubborn Horse 游戏不同的生成艺术研究。我从马的图像和轮廓出发，使用 OpenCV 提取边缘，并以 py5、噪声与轮廓转译方法生成动态线条和多种视觉变体。项目探索手工绘画、算法笔触与时间性图像之间的关系，重点在图像处理和生成式动态表达，而非游戏机制。

**技术与能力标签：** py5 · OpenCV · Contour Extraction · Generative Drawing · Motion Study

**创作职责：** 视觉实验、图像处理、生成式绘图与动画输出。

**已有本地短视频：** projects/horse-motion-study/horse-preview.mp4

## 8. GOOD BOY｜GOOD BOY
**类型：** Interactive Installation / Physical Computing
**卡片一句话：** 你以为自己在训练狗，实际上是系统在训练你。

**项目正文：** GOOD BOY 是一件关于公共空间规训与行为反馈的交互装置。观众握住实体狗绳，根据屏幕指令调整力度，尝试引导虚拟狗恢复“正确”状态；与此同时，监控视窗与评价机制持续记录观众的动作。作品通过实体传感器、实时通信、计算机视觉与 3D 动画，让看似轻松的互动逐渐显露系统对人的控制。

**技术与能力标签：** p5.js · Raspberry Pi Pico · HX711 / Load Cell · Web Serial · MediaPipe · Blender

**创作职责：** 概念研究、交互流程、实体传感器集成、p5.js 编程、Blender 动画和展陈设计。
